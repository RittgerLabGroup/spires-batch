# Configuration field glossary

[Reference index](README.md) · [CLI guide](../cli.md)

Short descriptions used when documenting the typed configuration schemas.
A model-qualified name distinguishes fields with the same name in different
contexts. This glossary is not a list of top-level configuration keys; see
the field guides for nesting and the complete JSON reference for constraints.

Generated by `scripts/build_config_reference.py`; see the index for maintenance.

| Field | Meaning |
| --- | --- |
| `Asset.kind` | lut, cloud_model, ancillary, climatology or r0; determines the required assets subdirectory. |
| `CloudMaskConfig.mode` | How daily cloud masks are provided/generated. See the enum and cross-field checks. |
| `ClusteringScienceConfig.enabled` | Enable clustered inversion rather than independent per-pixel fitting. |
| `R0Config.mode` | Build R0 explicitly or reuse existing immutable artifacts; never rebuild implicitly per date. |
| `StagingConfig.enabled` | Enable explicit scratch staging. Requires a staging root when true. |
| `account` | Slurm account authorized for the selected partition. |
| `adapter` | Discovery/static-context adapter name; use one registered by the maintained I/O package. |
| `albedo` | Daily canopy, ice and radiative calculations. |
| `algorithm` | Inversion solver identifier for generic daily retrieval; evaluated retained retrieval fixes its solver. |
| `apply_canopy_correction` | Apply the explicit sensor-matched canopy policy when true. |
| `apply_ice_adjustment` | Enable glacier-ice adjustment using the bound ice fraction. |
| `apply_valid_inversion_mask` | Apply the prepared inversion validity mask to inversion results. |
| `artifacts` | R0 artifacts with explicit tile, processing water year, source interval and output/source path. |
| `asset_version` | Directory/version label for externally prepared ancillary/climatology assets. |
| `assets` | Explicit individual external files to register. An empty list creates layout only, not a ready scientific inventory. |
| `average_horizontal_crown_radius` | Horizontal crown radius used in canopy geometry; retain the evaluated recipe value. |
| `average_vertical_crown_radius` | Vertical crown radius used in canopy geometry; retain the evaluated recipe value. |
| `background_tol` | Tolerance for background-reflectance clustering. |
| `build_prerequisites` | Include transitive prerequisites of selected jobs. False prevents surprise construction of omitted prerequisites. |
| `build_r0` | R0 preparation/selection parameters; no disk-backed or chunked summer execution. |
| `calculate_albedo` | Compute snow albedo using the configured albedo LUT. |
| `calculate_delta_vis` | Compute visible-band albedo change from impurities. |
| `calculate_radiative_forcing` | Compute radiative forcing; requires the corresponding irradiance inputs. |
| `cloud_mask` | Cloud generation/external-mask policy for daily requests. Matched historical/NRT preparation uses its own cloud coordinator. |
| `cloud_mask_application_stage` | Pre- versus post-inversion cloud application. Retained VIIRS retrieval requires post_inversion. |
| `cloud_mask_source_policy` | How external/native QA cloud evidence is combined; see supported enum. |
| `cloud_mask_var` | Dataset variable for an external cloud mask. |
| `cloud_shadow_mask_var` | Dataset variable for an external cloud-shadow mask. |
| `cluster` | Scheduler cluster; use blanca at this site. |
| `clustering` | Cluster settings for generic daily inversion. Not a tuning override for the fixed retained-retrieval worker. |
| `config_type` | Required public configuration kind; selects the interface, not a scientific algorithm. |
| `cosine_illumination_tol` | Clustering tolerance for cosine of illumination angle. |
| `cpus` | CPUs allocated per universal job. Cover the maximum thread count of all contained stages. |
| `cpus_per_task` | CPU allocation for a daily task; must cover configured worker threads. |
| `date` | ISO acquisition date for an explicitly registered input. |
| `depends_on` | Names of prerequisite jobs. Dependencies must exist and form an acyclic selected graph. |
| `device` | Inference device selector for supported cloud execution; do not assume a GPU allocation. |
| `domain` | Stable identifier for the complete tile domain that shares interpolation donors and state. |
| `durable_root` | Authoritative spipy assets/products/state root, separate from shared reflectance. |
| `environment_name` | Named environment activated by the daily renderer. |
| `execution` | Daily scheduler profiles, routing, concurrency, retry and explicit scratch staging. |
| `features` | Ordered scene features used by the clustering recipe; schema enumerates supported choices. |
| `files` | Explicit input records instead of, or alongside, discovery roots. |
| `ice_mask_var` | Optional external-ice dataset variable. |
| `id` | Unique human-readable asset identifier. |
| `initial_grain_radius_um` | Initial inversion grain-radius guess in micrometres. |
| `invert` | Generic daily inversion science settings. |
| `jobs` | Named jobs, each with kind, request, dependencies and optional resources. Names allow letters, digits, underscores and hyphens. |
| `kind` | initialize, daily, prepare, interpolation, acquire, or nrt. Each request follows its documented interface. |
| `low_reflectance_threshold` | Reflectance cutoff if low-reflectance masking is enabled. |
| `mask_low_reflectance_for_inversion` | Enable the optional low-reflectance inversion exclusion. |
| `mask_water_using_external_file` | Use an externally supplied water layer where bound. |
| `mask_water_using_reflectance_qf` | Use native reflectance QA to identify water. |
| `max_eval` | Maximum objective evaluations in generic inversion. |
| `max_solar_zenith` | Maximum valid solar zenith angle in physical degrees. |
| `memory` | Total Slurm memory per task, not per CPU. R0 uses 0 with exclusive allocation for all node memory; bounded positive sizes are required for interpolation. |
| `min_blue_reflectance` | Minimum blue reflectance for eligible land R0 candidates. |
| `min_obs_1km` | Minimum M-band observation count required by VIIRS preparation. |
| `min_obs_500m` | Minimum I-band observation count required by VIIRS preparation. |
| `mode` | Historical or nrt universal workflow mode; nrt jobs are forbidden in historical mode. |
| `model_manifest` | Path to the selected cloud model manifest, with its model assets available. |
| `ndvi_tie_epsilon` | R0 near-maximum NDVI tolerance used before near-nadir selection. |
| `output` | Output destination/settings. Use a new generation or run directory; do not overwrite accepted results. |
| `output_root` | Destination for immutable cloud products. |
| `partition` | Slurm partition; use blanca-snow or blanca-rittger, or approved preemptable overflow. |
| `platform` | Platform identity. Evaluated interpolation and native NRT orchestration currently require noaa20. |
| `playa_mask_var` | Optional external-playa dataset variable. |
| `preflight` | Validation level for planning; metadata checks are not a complete scientific validation. |
| `preparation` | Scene preparation and validity options; approved retrieval requires cloud application after inversion. |
| `qos` | Optional Slurm QoS, only when authorized by site policy. |
| `reflectance_roots` | Product/collection to authoritative archive-root mapping; initializer does not create, scan or download archives. |
| `reflectance_tol` | Tolerance for target-reflectance clustering. |
| `relative_path` | Individual file path relative to assets/, with the correct kind directory; no absolute path or parent traversal. |
| `representative_method` | Method for selecting cluster representatives. |
| `request` | Inline request object or JSON filename. Filename requests resolve relative to their own file; inline paths use the workflow file. |
| `required` | Missing required assets stop an explicitly requested staging operation. |
| `resources` | Per-job overrides for individual allocations and historical/interpolation/NRT schedulers. Batch overrides belong in request.execution.resources. |
| `reuse_policy` | Whether verified compatible existing cloud outputs may be reused. |
| `role` | Scientific role of an input or discovery root. Distinguishes reflectance, R0 sources and named assets. |
| `roots` | Input inventory discovery specifications, not download requests. |
| `run` | Run identity: name, sensor and platform. The workflow supplies sensor/platform to daily children. |
| `scheduler` | Scheduler configuration; unified workflows accept an inline policy or a policy file plus an optional science interpreter. Scientific arrays keep their own resource settings. |
| `schema_version` | Required integer 1: spipy v1.0.0 configuration baseline; independent of saved-state formats and package versions. |
| `scratch_root` | Fast working/cache root; not the sole durable home for state. |
| `selected_jobs` | Jobs to run; empty selects all. Omitting dependencies requires explicit existing-input handling. |
| `selection` | Tile, water-year and explicit date selection. No implicit dates are downloaded or created. |
| `sensor` | Sensor family. The universal workflow passes it to each supported child. |
| `show_progress` | Display preparation progress where supported; does not alter calculations. |
| `solar_zenith_tol` | Solar zenith clustering tolerance in physical degrees. |
| `stage_assets` | Copy registered available assets only when explicitly true; never transfers reflectance or full NRT history. |
| `stage_profiles` | Map daily stage names to named execution profiles; stage routing precedes the applicable fallback. |
| `staging` | Explicit input copying configuration; disabled does not mean durable storage is fast. |
| `storage` | Durable, scratch and shared reflectance roots; managed roots must not overlap shared archives. |
| `tile` | Native tile identifier, e.g. h08v05. Must be consistent with selection and source grid. |
| `tiles` | Complete native tile list; do not silently change an initialized or registered domain. |
| `time` | Slurm walltime, optionally day-prefixed. |
| `water_mask_values` | Land/water classification values considered water. |
| `water_mask_var` | Optional external-water dataset variable. |
| `water_year` | Processing water year, named by its ending year; e.g. summer 2025 R0 serves WY2026. |
| `water_years` | Processing water years. Adding a year does not build its annual assets automatically. |
